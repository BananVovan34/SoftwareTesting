ОТЧЕТ ПО ЛАБОРАТОРНОЙ РАБОТЕ № 3

Тема: Структурное тестирование. Тестирование «белого ящика».
Вариант 3. Вычисление элементарного многочлена Лагранжа.

1. Цель работы

Изучить тестирование базового пути. Для заданного фрагмента программы
построить граф управления, найти его цикломатическую сложность,
составить базовое множество независимых путей и проверить программу
на подобранных входных данных.

2. Задание

Необходимо вычислить значение элементарного многочлена L_k(t).
Заданы узлы x[0], x[1], ..., x[n], индекс k и точка t.
Количество узлов равно n + 1, потому что нумерация начинается с нуля.

Требования к данным:
  n >= 0;
  0 <= k <= n;
  все узлы различны;
  значения узлов и t являются конечными числами.

Программа вычисляет один многочлен L_k. Значения функции в узлах
для этой задачи не нужны.

3. Формула и ее смысл

L_k(t) = ∏ ((t - x[i]) / (x[k] - x[i])), где i = 0...n и i != k.

Знак ∏ означает произведение. Нужно вычислить дробь для каждого
индекса i, кроме k, и перемножить полученные значения.

Обозначения:
  x[i] — текущий узел;
  x[k] — выбранный узел;
  i — индекс текущего шага цикла;
  k — индекс узла, для которого строится многочлен;
  t — точка, в которой вычисляется результат;
  L — переменная, в которой накапливается произведение.

Значение L сначала равно 1. При умножении это начальное нейтральное
значение: оно не меняет первый множитель. Если бы L было равно 0,
результат после всех умножений тоже оставался бы нулем.

Индекс i = k пропускается. Иначе знаменатель оказался бы равен
x[k] - x[k] = 0. Поэтому в алгоритме есть проверка i == k
и оператор continue.

Например, заданы x = [0; 1; 2], k = 1, t = 1,5.
Множитель для i = 1 пропускается. Остается:

L_1(1,5) = ((1,5 - 0) / (1 - 0)) * ((1,5 - 2) / (1 - 2))
         = 1,5 * 0,5
         = 0,75.

У многочлена есть удобные свойства для проверки:
  при t = x[k] результат равен 1;
  при t = x[j], где j != k, результат равен 0.

В первом случае каждый множитель равен 1. Во втором случае один
из числителей равен нулю, поэтому все произведение равно нулю.
При n = 0 единственный индекс пропускается и L остается равным 1.

4. Исходный алгоритм

Ниже показан вычислительный фрагмент из метода Calculate без ввода данных.
Числа в комментариях обозначают вершины графа.

L = 1.0;                         // 1
i = 0;
while (i <= n) {                 // 2
    if (i == k) {               // 3
        ++i;                    // 4
        continue;
    }
    L *= (t - x[i]) / (x[k] - x[i]); // 5
    ++i;                        // 6
}
// Ответ находится в L          // 7

5. Потоковый граф

Потоковый граф показывает, в каком порядке могут выполняться участки
кода. Вершина — действие или проверка условия. Дуга — направленный
переход от одного участка к другому. Путь — последовательность вершин
от начала вычисления до завершения.

В данной работе выделены семь вершин:

1 — начальные значения L = 1 и i = 0;
2 — проверка i <= n;
3 — проверка i == k;
4 — увеличение i и переход continue;
5 — вычисление очередного множителя и умножение L;
6 — увеличение i после умножения;
7 — завершение вычисления.

  [1] -> [2] --Нет--> [7]
          |
         Да
          v
         [3] --Да--> [4] --возврат--> [2]
          |
         Нет
          v
         [5] -> [6] --возврат--> [2]

Полный список дуг:
  1 -> 2;
  2 -> 3, если i <= n;
  2 -> 7, если i > n;
  3 -> 4, если i == k;
  3 -> 5, если i != k;
  4 -> 2;
  5 -> 6;
  6 -> 2.

Всего в графе 7 вершин и 8 дуг. Вершины 2 и 3 являются предикатными

6. Цикломатическая сложность

Цикломатическая сложность характеризует структуру управления
программой. В методе базового пути она определяет размер базового
множества независимых путей графа.

Это не количество всех возможных запусков и не время работы.
Например, при увеличении числа узлов цикл выполняется дольше,
но новые условия в коде не появляются и сложность остается равной 3.

Первый способ — по дугам и вершинам:

V(G) = E - N + 2,

где E — число дуг, N — число вершин. Формула применяется здесь
к одному связному графу с одним входом и одним выходом.

V(G) = 8 - 7 + 2 = 3.

Второй способ — по предикатным вершинам:

V(G) = P + 1,

где P — число вершин с двумя исходами

V(G) = 2 + 1 = 3.

Третий способ — по областям плоского изображения графа:

V(G) = R.

У графа две внутренние области, образованные обратными переходами,
и одна внешняя область. Поэтому R = 2 + 1 = 3.
Учитываются области графа, а не отдельные стрелки или вершины.

7. Базовое множество независимых путей

В базовое множество включаются независимые пути графа. При выбранном
здесь порядке каждый следующий путь добавляет хотя бы одну дугу,
которой не было в предыдущих путях. Поэтому он дает новую структурную
проверку. Для этого графа базовое множество содержит три пути.

P1: 1 -> 2 -> 7.

Цикл не выполняется ни разу. После i = 0 условие i <= n должно быть
ложным, значит n < 0. При допустимом n >= 0 такой полный путь
невозможен. Это ограничение нужно указать, а не подбирать для него
обычный корректный пример.

Для отдельного структурного эксперимента S01 метод Calculate
вызван с n = -1, пустым массивом x, k = 0 и t = 0.
Ожидаемый результат: L = 1. Фактический результат: L = 1.
Путь по графу: 1 -> 2 -> 7.
Это проверка поведения исходного фрагмента за пределами допустимых
данных задачи. Она отдельно задана в автоматическом тесте; для обычного
вычисления многочлена нужно n >= 0 и не менее одного узла.

P2: 1 -> 2 -> 3 -> 4 -> 2 -> 7.

Данные: x = [3], n = 0, k = 0, t = 100.
На единственном шаге i == k, поэтому множитель пропускается.
Итог: L = 1.
По сравнению с P1 добавляются дуги 2 -> 3, 3 -> 4 и 4 -> 2.

P3: 1 -> 2 -> 3 -> 5 -> 6 -> 2 -> 3 -> 4 -> 2 -> 7.

Данные: x = [0; 2], n = 1, k = 1, t = 1.
При i = 0 вычисляется множитель (1 - 0) / (2 - 0) = 0,5.
При i = 1 выполняется пропуск. Итог: L = 0,5.
Добавляются дуги 3 -> 5, 5 -> 6 и 6 -> 2.

Итак, базовое множество графа: {P1, P2, P3}.
Пути P2 и P3 проверяются на допустимых данных. P1 проверен только
отдельным структурным экспериментом и недостижим в области n >= 0.

Нельзя просто взять любые три разных значения n и назвать их базисом.
Нужно показать, какие маршруты они вызывают и в чем их независимость.
Другой порядок тех же дуг сам по себе не дает новую дугу.

9. Ответы на контрольные вопросы

1) Что такое тестирование?
Это проверка программы с сопоставлением фактического поведения
и ожидаемого результата для выявления расхождений.

2) Что такое тест и что входит в процесс тестирования?
Тест задает данные, условия, действия и ожидаемый результат.
Тестирование включает подготовку, выполнение и оценку проверок.

3) Что такое структурное тестирование?
Это выбор тестов на основе внутреннего устройства программы:
операторов, условий, переходов и циклов.

4) В чем смысл тестирования «белого ящика»?
Тестировщик видит код и подбирает данные для выполнения конкретных
внутренних участков программы.

5) Какие у него особенности?
Проверяются разные ветви и режимы циклов. Учитываются состояние
переменных, достижимость путей и порядок вычисления условий.

6) Какие есть достоинства и недостатки?
Можно находить ошибки управления и измерять покрытие кода.
Нужен доступ к реализации, а полное покрытие не проверяет автоматически
все требования к программе.

7) Какие есть стратегии «белого ящика»?
Покрытие операторов, решений, условий, решений и условий,
комбинаций условий. Также применяется метод базового пути.

8) Что такое тестирование базового пути?
Это построение графа, выбор независимых путей и подбор тестов,
которые проверяют их выполнение с учетом достижимости.

9) Из чего состоит потоковый граф?
Из вершин и направленных дуг. Вершины обозначают участки кода
и условия, дуги — возможные переходы между ними.

10) Что такое цикломатическая сложность?
Это метрика структуры управления и размер независимого базиса графа.
Для данного фрагмента V(G) = 8 - 7 + 2 = 3.

11) Что такое базовое множество?
Это набор независимых путей графа. В нашей работе выбраны P1, P2, P3.
Для каждого пути указаны данные либо ограничение достижимости.

12) Каковы шаги метода базового пути?
Пронумеровать код, построить граф, вычислить сложность, выделить пути,
проверить их достижимость, подобрать данные, выполнить проверки
и сравнить полученные результаты с ожидаемыми.
