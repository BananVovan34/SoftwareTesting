# Арифметический калькулятор

Лабораторная работа № 1 по тестированию программного обеспечения. Приложение написано на C# и Windows Forms (.NET 8).

Выберите одну из операций `+`, `-`, `×`, `÷`, введите два числа и нажмите «Вычислить» или Enter. Поддерживаются десятичные дроби с запятой и точкой, а также записи `1,234.5` и `1.234,5`. Кнопка «Очистить» сбрасывает поля и операцию. После изменения чисел или операции прежний результат удаляется.

## Запуск

```powershell
dotnet run --project SoftwareTesting.csproj
```

## Проверки

```powershell
dotnet test SoftwareTesting.sln
```

Все 22 теста также видны в Visual Studio: **Тест → Обозреватель тестов**. [Подробный разбор кода](CODE_WALKTHROUGH.md) объясняет назначение каждого модуля и путь вычисления. Отчёт и шаги воспроизведения ошибок: [LAB1.md](LAB1.md).
