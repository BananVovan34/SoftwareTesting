# Лабораторные работы по тестированию ПО

Лабораторные работы № 1 и № 2 по тестированию программного обеспечения. Приложение написано на C# и Windows Forms (.NET 8).

Для лабораторной № 3 добавлен консольный проект `SoftwareTesting.Lab3` в том же решении. Вариант 3: вычисление элементарного многочлена Лагранжа. [Отчёт с графом и результатами](../output/pdf/Отчет_ЛР3_Вариант_3.pdf), [редактируемый текст отчёта](LAB3.md), [фактические результаты](Results/2026-11-03/lab3-cases.json).

```powershell
dotnet run --project Lab3/SoftwareTesting.Lab3.csproj
```

Команду выполнять из `E:\study\SoftwareTesting`. Без аргументов программа запрашивает узлы, индекс `k` и точку `t`. Пример запуска с аргументами: `dotnet run --project Lab3/SoftwareTesting.Lab3.csproj -- 1 1 0 2`; ожидаемый результат `0.5`. Для готовых примеров использовать `--demo`, для справки `--help`. В Visual Studio назначить `SoftwareTesting.Lab3` запускаемым проектом.

Тесты всего решения: `dotnet test SoftwareTesting.sln`. В текущем наборе 65 проверок: 43 для калькулятора и 22 для ЛР3. Подтверждения прогона ЛР3 сохранены в [Results/2026-11-03](Results/2026-11-03). Внутренний эксперимент с `n = -1` проверяет только недостижимый на допустимых входах путь исходного фрагмента; обычное приложение требует хотя бы один узел.

Выберите одну из операций `+`, `-`, `×`, `÷`, введите два числа и нажмите «Вычислить» или Enter. Поддерживаются десятичные дроби с запятой и точкой, записи `1,234.5`, `1.234,5` и целые с группами по три цифры `1.000.000`. Одиночная точка остаётся десятичным разделителем. От модуля результата `10¹²` показывается E-запись до 6 значащих цифр со знаком `≈`; вычисления остаются в `decimal`. Кнопка «Очистить» сбрасывает поля и операцию. После изменения чисел или операции прежний результат удаляется.
