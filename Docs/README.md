# Лабораторные работы по тестированию ПО

Лабораторные работы № 1 и № 2 по тестированию программного обеспечения. Приложение написано на C# и Windows Forms (.NET 8).

Для лабораторной № 3 в том же решении используется простой консольный проект `SoftwareTesting.Lab3`. Вариант 3: вычисление элементарного многочлена Лагранжа. Весь код находится в `Lab3/Program.cs`: `Main` вводит данные, `Calculate` выполняет цикл из методички.

[Простой текстовый отчёт по ЛР3](Отчет_ЛР3_простой.txt) содержит формулу, граф, расчёт сложности, базовое множество путей и пошаговый разбор каждого примера. Также доступны [отчёт с изображением графа](LAB3.md) и [результаты текущих проверок](Results/2026-11-10/lab3-cases.json).

```powershell
dotnet run --project Lab3/SoftwareTesting.Lab3.csproj
```

Команду выполнять из `E:\study\SoftwareTesting`. Программа запрашивает `n` (количество узлов минус один), затем каждый узел отдельно, индекс `k` и точку `t`. Дроби можно вводить с точкой или запятой. Например, для T04 последовательно ввести `2`, `0`, `1`, `2`, `1`, `1,5`; ответ `L = 0,75` (или `0.75` в зависимости от системного формата чисел). В Visual Studio назначить `SoftwareTesting.Lab3` запускаемым проектом.

Тесты всего решения: `dotnet test SoftwareTesting.sln`. В текущем наборе 53 проверки: 43 для калькулятора и 10 для ЛР3. Результаты прогона от 10.11.2026 находятся в [Results/2026-11-10](Results/2026-11-10). Эксперимент с `n = -1` относится только к пути без итераций; математическая задача предполагает `n >= 0`, различные конечные узлы и `0 <= k <= n`.

[Прежний PDF-отчёт](../output/pdf/Отчет_ЛР3_Вариант_3.pdf) и [результаты от 03.11.2026](Results/2026-11-03) описывают прежнюю реализацию с дополнительными проверками и записью маршрутов.

Выберите одну из операций `+`, `-`, `×`, `÷`, введите два числа и нажмите «Вычислить» или Enter. Поддерживаются десятичные дроби с запятой и точкой, записи `1,234.5`, `1.234,5` и целые с группами по три цифры `1.000.000`. Одиночная точка остаётся десятичным разделителем. От модуля результата `10¹²` показывается E-запись до 6 значащих цифр со знаком `≈`; вычисления остаются в `decimal`. Кнопка «Очистить» сбрасывает поля и операцию. После изменения чисел или операции прежний результат удаляется.
