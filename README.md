# Арифметический калькулятор

Лабораторная работа № 1 по тестированию программного обеспечения. Приложение написано на C# и Windows Forms (.NET 8).

Выберите одну из операций `+`, `-`, `×`, `÷`, введите два числа и нажмите «Вычислить» или Enter. Поддерживаются десятичные дроби с запятой и точкой. Кнопка «Очистить» сбрасывает поля и операцию.

## Запуск

```powershell
dotnet run --project SoftwareTesting.csproj
```

## Проверки

```powershell
dotnet run --project Tests/SoftwareTesting.Tests.csproj
```
